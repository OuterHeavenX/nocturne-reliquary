# Nocturne Reliquary — Design

Gothic cathedral-keep tower defense with job-relic cards, Warden XP, and per-tower AP boards.

- Phaser 3 runs the vigil (path, waves, towers, HUD).
- Three.js runs the living title keep, moon, and crystal.
- Balance lives in `data/`. Behaviors live in `towers/`. Runtime systems live in `src/`.
